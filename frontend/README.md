# VPC-SC Console (frontend)

React 19 + Vite + plain CSS. Colours come from `src/tokens.css` (see `../docs/color-palette.md`).
Data is sample data in `src/data.js`, mirroring `PRD.md` and `ARCHITECTURE.md`.

Pages: Dashboard, Perimeter, Violations (ID lookup), Runbook, Tests.

    npm install
    npm run dev      # http://localhost:5173
    npm run build
